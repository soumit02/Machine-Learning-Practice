# Machine Learning Practice Problems 🚀

Welcome to my Machine Learning practice repository! This project contains various basic and advanced ML problems that I am solving to gain hands-on experience. The primary goal of this repository is to solidify my understanding of core algorithms, data preprocessing, and model evaluation techniques.

## 🛠️ Technologies and Tools
*   **Programming Language:** Python
*   **Environment:** VS Code, Jupyter Notebook
*   **Operating System:** Windows
*   **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, scikit-learn

## 📂 Project Structure
*   `src/` - Contains all the Jupyter Notebook (`.ipynb`) files with the problem solutions and explanations.
*   `requirements.txt` - List of all Python dependencies required to run the notebooks.
